# TOGAF templates

Section-skeleton markdown templates for every TOGAF 10 deliverable used by this toolkit.
The slash commands in `.cursor/commands/togaf/` (and the Claude/Copilot equivalents)
read these templates as the canonical structure when authoring deliverables.

You can edit them in place to tailor the framework to your organisation. Re-run
`togaf upgrade .` to overwrite them with the bundled defaults.
